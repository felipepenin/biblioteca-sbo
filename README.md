# Biblioteca de SBO 📚

Sistema de gerenciamento de biblioteca desenvolvido em Python como projeto de estudo, com foco em lógica de programação, funções e Programação Orientada a Objetos (POO).

## Funcionalidades

- Cadastrar livros.
- Listar livros cadastrados.
- Buscar livros pelo título.
- Emprestar livros.
- Devolver livros.
- Verificar a disponibilidade dos livros.
- Validar opções do menu.

## Tecnologias utilizadas

- Python 3
- Programação Orientada a Objetos (POO)
- Git e GitHub

## Estrutura do projeto

```text
biblioteca-sbo/
├── main.py
├── classe.py
├── funcoes.py
├── README.md
└── .gitignore
```

## Como executar

1. Instale o Python 3.
2. Clone este repositório ou baixe seus arquivos.
3. Abra a pasta do projeto no terminal.
4. Execute:

```bash
python main.py
```

No Windows, também é possível utilizar:

```bash
py main.py
```
